trak // demo day

What does it do?

A social step-count fitness app. Compete with friends on live leaderboards, send powerup attacks, and stay motivated through friendly competition.

What did you learn?

  • Git & GitHub collaboration on a team: PRs, merge conflicts, shared history
  • Layered architecture to decouple parallel tracks. Abstract repo interfaces let frontend mock the backend until the API was settled; still didn't fully eliminate blocking
  • Backend as a service: creating backend APIs to match what the app needs, plus overall deployment management

Demo flow

  1. Login (step counter ticking live)
  2. Add friend by username
  3. Add friend by QR code
  4. Adjust display name → leaderboard updates
  5. Powerup / attack a friend
  6. Historical leaderboards
  7. Push notification via friend add
